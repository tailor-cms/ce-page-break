# Section Break

Tailor CMS page break content element.

**Type:** `BREAK`

## Data

No configurable fields. The element has no authored data.

## Edit

- Static preview rendering a section break label with icon

## Display

- Renders a "Next" button that emits an `interaction` event to advance the reader

## Development

```sh
pnpm dev     # Preview :8080 | Edit :8010 | Display :8020 | Server :8030
pnpm build
pnpm lint
pnpm test
```

## Run with Docker

```sh
docker compose up
```
